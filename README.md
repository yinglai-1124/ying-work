# YING LAI | 個人自我介紹與履歷網頁 🩵

> 嗨嗨！我是稚穎，歡迎認識我~~ ☁️

一個以純原生 HTML、CSS 與 JavaScript 打造的個人簡約風格自我介紹網頁，以「**天空藍 + 純白**」為主題色調，具備乾淨舒適的視覺排版與捲動淡入動態效果。

---

## ✨ 網頁亮點

- **色彩風格**：天空藍（#5ca4ea）+ 純白（#ffffff），簡約、舒適、乾淨、可愛。
- **捲動動畫**：原生 Intersection Observer 打造流暢淡入效果。
- **響應式設計 (RWD)**：手機與電腦螢幕皆能完美呈現。
- **無框架依賴**：單一 `index.html` 即可直接在瀏覽器預覽。
