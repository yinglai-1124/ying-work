一個以純原生 HTML、CSS 與 JavaScript 打造的個人簡約風格自我介紹網頁，以「**天空藍 + 純白**」為主題色調，具備乾淨舒適的視覺排版、捲動淡入動態效果與豐富的按鈕互動功能。

---

## ✨ 網頁亮點

- **色彩風格**：天空藍（#4fa0ee）+ 純白（#ffffff），簡約、舒適、乾淨、可愛。
- **捲動動畫**：原生 Intersection Observer 打造流暢淡入效果。
- **全方位按鈕互動**：
  - 💖 **送顆愛心打氣**：即時點讚計數與天空藍/粉色愛心飄浮特效。
  - 📋 **一鍵複製名片 / 座右銘**：快速將個人資訊與座右銘複製到剪貼簿。
  - 🔮 **彩蛋問候切換**：點擊頭像或問候標籤可隨機輪播趣味問候語。
  - 🔍 **觀察雷達 & 側空翻集氣**：技能卡片專屬互動按鈕。
  - ⬆️ **平滑回到頂部**：右下角常駐浮動按鈕與平滑錨點跳轉。
- **響應式設計 (RWD)**：手機與電腦螢幕皆能完美呈現。
- **無框架依賴**：單一 `index.html` 即可直接在瀏覽器預覽。
